# Code of Conduct

This project follows the Contributor Covenant, version 2.1.

## Our pledge

We pledge to make participation in this project a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of
experience, education, socio-economic status, nationality, personal appearance,
race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and ask clarifying questions.
- Give and accept feedback gracefully.
- Focus on what is best for the project and its users.
- Respect privacy: never post real voices, private media, transcripts, API keys,
  or personal data.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized attention, deliberate
intimidation, and publishing others' private information are not tolerated.

## Enforcement

Maintainers may remove, edit, or reject contributions and comments that violate
this code, and may temporarily or permanently ban contributors for behavior they
deem inappropriate.

Report incidents privately through the repository's maintainer contact or a
GitHub Security Advisory if the report is sensitive. Reports will be reviewed as
quickly as possible and handled confidentially.
