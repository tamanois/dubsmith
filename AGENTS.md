
# Context

The goal of the project is to allow the conversion of videos, in a target language, and in the same voice timbre of the speakers, but if possible the target language "accent". Allowing to make video available to a wider audience, breaking then the language barrier when communicating.
We want to use as most as possible open models that can be run on consumer. For llm specifically (if needed), app should be open ai compatible, in case we decide to use a cloud model.

## Simplest description
- Take a video as input, detect the language of the speakers, identify each voice and translate the video so that we can have a new video with speakers speaking in a target language, with their own voice timbre, and if possible the accent of the target language (but their voice still)
