soundfile

# Pipeline stages
qwen_tts                # voice cloning / TTS (Qwen3-TTS)

pyloudnorm              # EBU R128 loudness measurement + normalisation
openai                  # OpenAI-compatible client used for translation

# Optional: multi-speaker dubbing. Provides the speaker-verification model
# (ERes2NetV2, ~30 MB, cached under ~/.cache/modelscope) used to tell voices
# apart, so each speaker can be cloned from their own voice. Without it every
# line is dubbed in a single voice, which is the behaviour of --diarizer none.
#
# Heavy but self-contained: the many extras funasr declares are all guarded by
# `extra ==` markers, so only its actual runtime dependencies are installed.
# If pip tries to change numpy/librosa/transformers, pin the ones you already
# have first: pip install -c <(pip freeze) funasr
#funasr

# Optional: faster TTS inference. Needs a C++ toolchain and a compatible GPU;
# the pipeline falls back to PyTorch SDPA without it.
#flash-attn

# Optional: background preservation (keeps the original music and ambience).
# Without it the dub replaces the whole audio track, so music and room tone are
# lost. The weights (~80 MB) live in the torch hub cache and download on first
# use, or on demand with:  python dub.py models --download demucs
#demucs

# Optional: CUDA 12 runtime libraries for **GPU speech recognition**.
# CTranslate2 (used by faster-whisper) links against CUDA 12 specifically, while
# recent torch wheels ship CUDA 13 (which provides libcublas.so.13). On such a
# machine ASR logs "libcublas.so.12 is not found or cannot be loaded" and only
# runs on CPU. Installing these two wheels fixes GPU ASR; the pipeline preloads
# them automatically, so no LD_LIBRARY_PATH export is needed.
#nvidia-cublas-cu12
#nvidia-cudnn-cu12
